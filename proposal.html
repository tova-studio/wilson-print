What we found

We reviewed http://www.wilsonprint.co.nz using publicly available information:

  • Not mobile-friendly. The page has no responsive viewport tag, so phones show a shrunken desktop layout.
  • Built with legacy page techniques. 7 deprecated tags and 4 layout tables found (modern sites use responsive CSS).
  • No easy way to get in touch. No tap-to-call link and no enquiry form on the homepage.
  • No local-business search markup. No structured data, so Google has less to show for the business.
